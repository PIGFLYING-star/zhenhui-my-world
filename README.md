# Future Scroll World

A Cloudflare Pages ready immersive scroll-controlled landing page.

## Structure

- index.html: main page
- scrub-engine.js: scroll/video controller
- assets/images: replace placeholders with generated WebP scenes
- assets/video: replace placeholders with generated MP4 camera flights

## Deployment

Upload this folder to GitHub and deploy with Cloudflare Pages.

Build command:
exit 0

Output directory:
/

## Media

Replace:
assets/video/*.mp4
assets/images/*.webp

with your AI-generated assets.
